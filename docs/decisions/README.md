# Architecture decision records

Use this folder for future numbered decisions such as `0001-result-interface.md`. No decisions are ratified by this directory skeleton.

A useful record includes the problem/context, options and tradeoffs, decision status (proposed, accepted, or superseded), date, accountable owner, affected interfaces, and evidence or checks needed. Link the relevant research and interface documents; update or supersede the record when the decision changes.

Keep the current research in the existing five subsystem documents and future detailed contracts in [interfaces/](../interfaces/). Record actual team agreement explicitly rather than treating a proposal as an accepted requirement.
